## Basic Setup

```ts title="index.ts" icon="/icons/typescript.svg"
import { serve } from "bun";
const jsx = <Foo bar="baz" />;

const server = Bun.serve({
  routes: {
    "/api/status": new Response("OK"),
  },
});
```

See [routing](/runtime/http/routing), the [Bun.serve reference](/runtime/bun-apis#bun-serve) and the [Node.js docs](https://nodejs.org/api/http.html).
Start with{" "}<code>bun run</code> and a<br />break.

<Note>Routes need Bun v1.2.3+.</Note>

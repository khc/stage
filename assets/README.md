# Stage logo assets

The Stage logo includes the “Agentic Platform” tagline. All files use a 1376 × 768 canvas.

| File | Description |
| --- | --- |
| [image.jpeg](image.jpeg) | Original artwork used as the visual reference. |
| [image.svg](image.svg) | Scalable vector recreation with redrawn shapes and gradients. |
| [image-v2.svg](image-v2.svg) | Vector recreation with a soft glow around “Stage.” |
| [image-v3.svg](image-v3.svg) | Soft wordmark glow with slightly lighter colored blobs. |

The SVGs use Abril Fatface Regular for “Stage” and Montserrat at weight 650 for “Agentic Platform.” The lettering is stored as vector outlines, so the SVGs render without installed fonts. [Abril Fatface](https://github.com/google/fonts/tree/main/ofl/abrilfatface) · [Montserrat](https://github.com/google/fonts/tree/main/ofl/montserrat)

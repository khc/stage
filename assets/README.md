# Stage logo assets

The Stage logo includes the “Agentic Platform” tagline. Both files use a 1376 × 768 canvas.

| File | Description |
| --- | --- |
| [image.jpeg](image.jpeg) | Original artwork used as the visual reference. |
| [image.svg](image.svg) | Scalable vector recreation with redrawn shapes and gradients. |

The SVG uses Abril Fatface Regular for “Stage” and Montserrat at weight 650 for “Agentic Platform.” The lettering is stored as vector outlines, so the SVG renders without installed fonts. [Abril Fatface](https://github.com/google/fonts/tree/main/ofl/abrilfatface) · [Montserrat](https://github.com/google/fonts/tree/main/ofl/montserrat)
